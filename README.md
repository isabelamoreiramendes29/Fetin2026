# Cemtinel — Sistema de Monitoramento de Cimento

Aplicativo mobile desenvolvido em React Native com Expo para monitoramento de cimento em construtoras.

## Sobre o Projeto

O **Cemtinel** permite que construtoras acompanhem em tempo real:

- Temperatura do cimento durante a obra
- Localizacao dos caminhoes de entrega
- Gestao financeira das obras

Desenvolvido como projeto academico para a **FETIN** (Feira de Tecnologia).

## Tecnologias

- React Native
- Expo SDK 54
- React Navigation
- Context API
- react-native-chart-kit
- react-native-maps

## Telas do Aplicativo

- Boas-vindas (Welcome)
- Login
- Cadastro de Usuario
- Selecionar Obra
- Cadastro de Obra
- Grafico de Temperatura
- Historico de Temperaturas
- Localizacao do Caminhao
- Financeiro

## Como Executar

1. Clone o repositorio:
```bash
git clone https://github.com/isabelamoreiramendes29/Fetin2026.git
```

2. Instale as dependencias:
```bash
npm install
```

3. Inicie o servidor Expo:
```bash
npx expo start
```

4. Abra o **Expo Go** no celular e escaneie o QR Code
